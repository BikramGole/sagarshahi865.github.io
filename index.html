    Fitness Hub

    A fitness platform where members track goals, nutrition and progress, browse an exercise library, and buy from a built-in store.

    Team CodexDetails

    What it does

    • User profiles that members can edit
    • Dashboard with a progress chart
    • Goals, nutrition and progress tracking, each with full create, read, update and delete
    • Seeded exercise library
    • Store with a session-based cart and Stripe Checkout in test mode

    How it is built

    Staff permissions are set up through user groups, sample data loads with seed commands, and a GitHub Actions workflow runs migrations and tests on every change.
